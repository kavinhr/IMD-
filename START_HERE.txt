  QUICK START (3 STEPS)
================================================================================

STEP 1: Run Setup
-----------------
Double-click: setup.bat
(This installs Python dependencies)

STEP 2: Configure Database
---------------------------
1. Open PostgreSQL (pgAdmin or psql)
2. Run these commands:
   
   CREATE DATABASE wdms_db;
   CREATE USER wdms_user WITH PASSWORD 'wdms_password';
   GRANT ALL PRIVILEGES ON DATABASE wdms_db TO wdms_user;
   \c wdms_db
   GRANT CREATE ON DATABASE wdms_db TO wdms_user;

3. Edit config.py and update the password if you changed it

STEP 3: Initialize & Run
-------------------------
In command prompt:
   python init_db.py
   python run.py

Then open browser: http://localhost:5000
Login: admin / admin123

================================================================================
  COMMON FIRST-TIME ISSUES
================================================================================

❌ "Python is not recognized"
   → Install Python from python.org and check "Add to PATH"

❌ "PostgreSQL connection failed"
   → Make sure PostgreSQL service is running
   → Check username/password in config.py

❌ "pip install fails"
   → Run: python -m pip install --upgrade pip
   → Then run setup.bat again

❌ "Port 5000 already in use"
   → Edit run.py, change port to 5001
   → Or kill process using port 5000

❌ "Module not found" errors
   → Make sure you activated virtual environment:
     venv\Scripts\activate
   → Then run: pip install -r requirements.txt
